🚀 My Project: 


AI-Powered Personal Journal Assistant (AI Diary) 🧠📓
Hey everyone! 👋


As a Java and ML developer, I wanted to build something that connects AI with everyday life — something personal yet intelligent.
That’s how AI Diary was born — an AI-powered personal journal assistant that lets you record your daily experiences through both text and voice.

🧩 What it can do right now:
✍️ Users can write or speak their daily stories.
🗃️ Entries are stored in a Relational Database (PostgreSQL) in a clean, structured format.
🔍 Users can search past entries by date or keywords — for example:
“Show me my notes from last Sunday.”
🖼️ Supports image attachments, so you can save photos related to your day.
📅 You can filter or search images by date or keywords — e.g.,
“Show me images from July 20” or “Show me the images from the beach.”
🎧 You can even listen to your own recorded voice from any specific day!
⚙️ Tech Stack & Highlights:
☕ Java + Spring Boot for clean, modular, and scalable backend development
🗃️ PostgreSQL for structured data storage and management
🧠 LLM integration (for understanding and future conversational capabilities)
🧩 Focused on clean architecture and key design patterns (Factory, Strategy, Singleton, Chain of Responsibility)
⚡ Implements concurrency handling for smooth, efficient performance
🔮 Built with scalability in mind — ready to integrate Vector Databases for semantic search in upcoming versions
🧠 Future Vision:
 In future updates, I plan to integrate Vector Database search so AI Diary can understand natural questions like:
“What did I do at the beach last month?”
 and recall relevant moments intelligently using embeddings.
💡 This project taught me a lot about system design, concurrency, and bringing AI concepts into a Java + Spring Boot backend.
 It’s a project that feels close to me — because it’s all about combining memories and intelligence.
